# AI-Based Plagiarism Detection System

## 🚀 Overview
This project is an AI-powered plagiarism detection system that compares large text/PDF documents and detects similarity using NLP techniques.

## 📌 Features
- Upload two documents (PDF/Text)
- Extract text automatically
- Chunk-based comparison for large files
- AI-based similarity detection
- Pie chart visualization of plagiarism percentage
- PDF report generation
- Simple web interface using Flask

## 🧠 Tech Stack
- Python
- Flask
- NLP (TF-IDF / similarity model)
- Scikit-learn
- Matplotlib
- PyPDF2

## 📊 Output
- Plagiarism percentage
- Visual charts (Pie chart)
- Downloadable report
